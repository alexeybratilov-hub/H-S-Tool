# Соглашение по структуре папок

1. Имена папок используются латиницей.
2. Русские названия хранятся внутри файлов, реестров и интерфейса.
3. Каждая компания изолируется через company_id.
4. Данные одной компании не используются при генерации документов для другой компании.
5. Нормативная база хранится отдельно от документов компаний.
6. Шаблоны хранятся отдельно от реальных документов.
7. Черновики, экспортированные файлы, логи и бэкапы разделяются.
8. Реальные персональные данные не размещаются в репозитории.
