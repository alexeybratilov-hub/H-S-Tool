# Юридический дисклеймер

Система OT Local Agent не является источником юридической истины.

Нормативные требования, перечень документов, периодичности, нормы СИЗ, требования по СОУТ, оценке рисков, медосмотрам, психиатрическим освидетельствованиям, электробезопасности и ответственности должны загружаться пользователем из проверенных актуальных источников и подтверждаться специалистом по охране труда.

ИИ готовит только черновики. ИИ не утверждает, не подписывает, не отправляет и не принимает юридически значимые решения.

Ответственность за проверку, утверждение и применение документов остаётся за должностными лицами организации.
