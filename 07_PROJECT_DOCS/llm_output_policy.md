# Политика вывода LLM

1. LLM используется только для подготовки черновиков, пояснений, извлечения кандидатов и предложений правил.
2. LLM не является источником юридической истины.
3. Внутренние рассуждения модели, блоки reasoning / thinking / analysis не являются частью документа.
4. Если модель вывела reasoning-блок, система не должна переносить его в черновик документа как основной текст.
5. Лювый вывод LLM должен иметь статус: LLM_SUGGESTED, PRELIMINARY или REQUIRES_VERIFICATION, если не подтверждён пользователем.
6. Финальный документ утверждается только специалистом по охране труда.
7. Автоматическое утверждение, подписание и отправка документов запрещены.
