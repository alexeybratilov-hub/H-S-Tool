# Политика безопасности

1. Приложение работает только локально.
2. Streamlit должен быть доступен только на 127.0.0.1.
3. Облачная синхронизация реальных персональных данных запрещена.
4. Автоматическая отправка документов запрещена.
5. Автоматическое утверждение документов запрещено.
6. Диагнозы не хранятся.
7. Подробные медицинские заключения не хранятся.
8. Психиатрические диагнозы не хранятся.
9. Для медосмотров и психиатрических освидетельствований хранятся только metadata: дата, срок, код результата, признак ограничений, ссылка на внутренний документ.
10. Экспорт DOCX выполняется только вручную после проверки пользователем.
11. Реальные персональные данные не должны попадать в Git, логи, тесты и внешние сервисы.
